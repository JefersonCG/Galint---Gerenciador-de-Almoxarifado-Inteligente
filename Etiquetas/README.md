# Etiquetas

Esta pasta agrupa arquivos soltos de etiqueta e utilitários relacionados que não precisam ficar na raiz do repositório.

## Uso desta pasta

- layouts exportados manualmente
- arquivos .galintetq fora do fluxo ativo do app
- utilitários de barcode, scanner e ícones ligados ao tema de etiquetas

## Importante

Os layouts usados diretamente pelo Barcode Studio continuam em data/label_layouts.

O backend agora aceita subpastas dentro desse diretório runtime, como data/label_layouts/Etiquetas, mas esta pasta da raiz continua reservada para utilitários, exports e arquivos soltos que não precisam aparecer automaticamente dentro do editor.
