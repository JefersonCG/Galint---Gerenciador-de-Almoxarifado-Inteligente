Guia do configurador de unidades dinâmicas
Unidades Dinâmicas

Guia intuitivo do configurador

Use este guia sem sair do cadastro. A lógica é simples: escolher a família da medida, cadastrar as unidades reais do item e dizer como uma unidade vira outra.

Como pensar o configurador

O configurador tem três blocos. Primeiro você habilita as grandezas. Depois escolhe as unidades do item. Por fim, define as conversões entre elas.

1. Grandeza

Grandeza é a família da medida. Ela responde o que aquela unidade mede.

Unidade Massa Volume Comprimento

2. Código

Agora o código deixa de ser digitado manualmente. Você escolhe a unidade pronta e o sistema preenche o identificador curto automaticamente.

Exemplos
Unidade → codigo: unidade Litro → codigo: litro Caixa → codigo: caixa Peça → codigo: peca

3. Nome

Nome também é preenchido automaticamente a partir da unidade escolhida. Ele é o rótulo legível na tela.

4. Base

A unidade base é a referência principal do item. Se o item é controlado por peça, normalmente a base é Unidade. Se é controlado por litro, a base costuma ser Litro.

Regra prática: marque como base a unidade em que você quer enxergar o estoque e fazer as conversões principais.

O que preencher em cada campo

Unidade

Selecione a opção pronta. Isso já preenche Código e Nome.

Código

É só conferência. Ele é gerado automaticamente pela unidade escolhida.

Nome

Também fica automático para manter padrão visual e evitar divergência.

Grandeza

Permanece ajustável. O sistema sugere uma grandeza inicial, mas você pode trocar se precisar.

Conversão

O fator sempre significa: 1 unidade de origem equivale a quantas unidades de destino.

Exemplo de leitura
De: caixa Para: unidade Fator: 12 Resultado: 1 caixa = 12 unidades

Exemplos reais

Parafuso em caixa

Grandeza: Unidade Base: unidade Unidade adicional: caixa Conversão: 1 caixa = 100 unidades

Tinta em lata

Grandeza: Volume Base: litro Unidade adicional: lata Conversão: 1 lata = 18 litros

Cabo em rolo

Grandeza: Comprimento Base: metro Unidade adicional: rolo Conversão: 1 rolo = 100 metros

Cimento em saco

Grandeza: Massa Base: quilo Unidade adicional: saco Conversão: 1 saco = 20 quilos

Erros mais comuns

  1. Escolher uma grandeza e não cadastrar nenhuma unidade daquela família.
  2. Esquecer de marcar uma unidade como base.
  3. Inverter a conversão e cadastrar o fator ao contrário.
  4. Usar uma unidade pronta com grandeza incompatível sem revisar.
  5. Criar várias unidades, mas nenhuma conversão prática entre elas.
Teste rápido: leia a regra em voz alta. Se a frase “1 X = Y Z” fizer sentido, a conversão normalmente está correta.
