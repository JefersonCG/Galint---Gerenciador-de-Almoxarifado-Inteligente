❌ PROBLEMAS E SOLUCOES:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PROBLEMA: "Node.js nao encontrado"
└─ SOLUCAO: Instalar Node.js e reiniciar PowerShell

PROBLEMA: "Cannot connect to Metro"
└─ SOLUCAO: Executar "npm start -c" (limpa cache)

PROBLEMA: "Network request failed"
└─ SOLUCAO 1: Verificar se Flask esta rodando
└─ SOLUCAO 2: Testar com HTTP (porta 5000)
└─ SOLUCAO 3: Verificar mesma rede Wi-Fi

PROBLEMA: QR Code nao aparece
└─ SOLUCAO: Pressionar 'w' no terminal

PROBLEMA: Camera nao funciona
└─ SOLUCAO: Permitir camera em Config > Apps > Expo Go

PROBLEMA: App demora muito
└─ NORMAL: Primeira vez demora 1-2 minutos
└─ SOLUCAO: Se continuar, executar "npm start -c"

PROBLEMA: "Token invalido"
└─ SOLUCAO 1: Testar conexao antes de logar
└─ SOLUCAO 2: Verificar IP/porta corretos
└─ SOLUCAO 3: Verificar se usuario existe
