1 📱 Instalar Expo Go no Celular
  1. Abra a Play Store no seu Android
  2. Pesquise por Expo Go
  3. Instale o aplicativo
  4. Abra uma vez para configurar
⚠️ Importante: Certifique-se de que o celular está na MESMA rede Wi-Fi que o computador!
2 💻 Verificar Node.js no Computador

Abra o PowerShell e digite: node --version

  • Se aparecer a versão: Perfeito! Prossiga para o próximo passo.
  • Se der erro: Baixe e instale Node.js de nodejs.org
3 🚀 Executar Instalador Automático
  1. Abra a pasta galint-mobile
  2. Localize o arquivo instalar_e_rodar.ps1
  3. Clique com botão direito → "Executar com PowerShell"
  4. Aguarde a instalação (3-5 minutos)
📥 Instalação: O script baixará aproximadamente 500MB de dependências. Aguarde pacientemente!
4 📷 Escanear QR Code
  1. Após a instalação, um QR Code aparecerá no terminal
  2. Abra o app Expo Go no celular
  3. Toque em "Scan QR Code"
  4. Aponte a câmera para o QR Code no computador
  5. O app GALINT abrirá automaticamente (pode demorar 30-60s na primeira vez)
5 ⚙️ Configurar Servidor no App

Na primeira tela do app, configure:

IP do Servidor: 10.0.0.245
Porta: 5000
Protocolo: HTTP
  1. Preencha os campos acima
  2. Clique em "Testar Conexão"
  3. Aguarde aparecer "Conexão OK!"
  4. Digite suas credenciais (matrícula e senha)
  5. Marque "Lembrar de mim" se desejar
  6. Clique em "Entrar"

🎉 Tudo Pronto!

Agora você pode usar o GALINT Mobile para:

Escanear Códigos de Barras
Cadastrar Itens
Pesquisar no Estoque
Consultar em Tempo Real
📸 Como Usar o Scanner
  1. Na tela de Estoque, toque no botão de câmera (flutuante)
  2. Permita acesso à câmera quando solicitado
  3. Aponte para o código de barras
  4. O app detecta automaticamente e vibra
  5. Item encontrado: Mostra detalhes
  6. Item não encontrado: Abre tela de cadastro
❓ Problemas Comuns

"Network request failed"

  • Verifique se o servidor Flask está rodando
  • Confirme se está na mesma rede Wi-Fi
  • Tente com HTTP (porta 5000)

"Cannot connect to Metro"

  • Execute no PowerShell: npm start -c

QR Code não aparece

  • Pressione w no terminal
  • Ou pressione i para ver URL manual
