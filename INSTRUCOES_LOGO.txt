🔧 CASO A LOGO NÃO APAREÇA:

1. Verifique se o arquivo está em:
   galint-mobile/assets/galint-logo.png

2. Verifique o nome do arquivo (exatamente "galint-logo.png")

3. Reinicie o Expo:
   - Pare o servidor (Ctrl+C)
   - Execute novamente: npm start

4. Se necessário, limpe o cache:
   npm start -- --clear

=====================================================

✨ PRÓXIMOS PASSOS:

Após confirmar que a logo aparece corretamente no Expo Go,
gere um novo APK para produção:

cd galint-mobile
.\build_apk.ps1 -Profile "preview" -ExpoToken "SEU_TOKEN"
